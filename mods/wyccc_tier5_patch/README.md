# 五级小城美化兼容

空壳 Pack：`wyccc_tier5_patch.pack`。只包含功能标记，实际兼容配置由 Wyccc's Mod Manager 在启动游戏前生成。

管理器扫描到这个 Pack 即视为已安装，支持工坊、Data 和本地来源；不要求启用这个 Pack。条目默认隐藏，可通过“显示隐藏的 MOD”查看。兼容面板中的选项默认关闭，只有已安装这个 Pack 且启用 `MinorTierFiveFourAll`（工坊 ID `3071058075`）时才可勾选。

启用选项后，管理器读取原版和当前加载 MOD 的建筑等级、城市展示映射和模型配置，自动补齐小城展示链的四、五级。缺少高级外观时沿用三级模型，已经完整的高级外观保持原样。支持任意使用这些展示表的城市美化 MOD，不依赖固定 MOD 名或城市名单。识别同路径整表覆盖并恢复必要的展示记录，模型配置数字键碰撞时分配新键，保持其它模型可用。

补丁沿用本体替换城市的脚本、MCT 开关及执行顺序。真实建筑的效果、槽位和驻军保持原样。关闭选项、移除标记 Pack 或停用五级小城 MOD 后，下次通过管理器启动时清理生成的兼容 Pack。

构建空壳 Pack：

```powershell
.\.venv-build\Scripts\python.exe scripts\build_tier5_feature_mod.py
```

输出在本目录。此命令只创建功能标记 Pack，不构建管理器程序、不部署已安装程序，也不上传工坊。上传时可将 `3071058075` 设为必需物品。

展示链的各级必须配有建筑 UI 记录。源 MOD 未提供时，生成器使用同类建筑的现有记录作为模板；无法取得模板则跳过该链，避免只增加建筑等级。合并 UI 时使用 `building/culture/subculture/faction` 四个主键字段，已有配置保留。生成器版本更新为 3，旧版本缓存会自动重建。

离线验证涵盖功能门槛、Pack 隐藏、覆盖优先级、展示链生成、建筑 UI 数组边界及缓存清理。战役外观仍需玩家实测。
